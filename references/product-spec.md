# 产品定义书

> 版本：v1.0 ｜ 状态：已定稿（方向由「纯适老」修正为「普惠 + 适老设计」）
> 决策依据见本地研究资料（未随仓库分发）：《客群数据核实与定位修正》《全流程点单 Skill 规划方案》。

---

## 一、一句话定位

**说一句话，明明白白点好一餐。**

对话式麦当劳点餐助手：覆盖「选餐 → 省钱 → 算价 → 下单 → 取餐 → 售后」完整流程，并把**工信部适老化设计规范**作为硬标准落地。

---

## 二、为什么是「普惠 + 适老设计」而不是「纯适老」

| 判断 | 依据 |
|---|---|
| ❌ 不做「只面向老人」 | 麦当劳消费主力是 20~35 岁；银发族**点过外卖仅 12.5%**、**能自行线上点外卖不足 20%**，线上需求池太小 |
| ✅ 做「面向全体 + 适老标准」 | 适老规范（大字号、无诱导付款、行为可撤销、不用专业词）**对所有人都有价值**，是设计标准而非人群边界 |
| ✅ 高频场景选「早餐 / 通勤」 | 一手数据：实测账号 13 张券中 10 张为早餐券；麦当劳在猛推早餐（6 折卡、9.9 元早餐两件套） |
| ✅ 保留社会价值叙事 | 可坦然声明「对齐工信部适老化规范」，不虚构人群 |

## 三、目标人群

| 层级 | 人群 | 场景 | 说明 |
|---|---|---|---|
| **核心** | 日常通勤 / 早餐人群（上班族、学生） | 早上赶时间点一份早餐；午间快速解决 | 覆盖绝大多数消费者，最高频 |
| **核心** | 数字操作不熟练者（中老年、不熟悉多步操作的人） | 想点但不敢用 App / 自助机 | **靠设计标准覆盖，不单独定位** |
| **增益** | 替家人（父母、长辈）点餐的子女 | 异地给父母点一份早餐 | 数据支撑：35.4% 的银发线上消费由子女下单 |

## 四、与官方 App 的差异（必须能一句话说清）

官方 App 已能做点单、领券、积分。**本 Skill 的价值不在"能点餐"，而在以下 6 点：**

| # | 差异点 | 具体表现 |
|---|---|---|
| 1 | **编排** | 不用说清「到店 / 得来速 / 外送」，系统按地址、时段、预算自动判断取餐方式 |
| 2 | **对比** | 不是给一个方案，而是给 ≥3 个方案的真实计价对比表（每个价格都来自 `calculate-price`） |
| 3 | **明确** | 金额永远三行：原价 / 优惠 / 实付。不合并、不含糊 |
| 4 | **可逆** | 写操作（下单等）明文提示**可在 10 分钟内撤销**（对齐工信部要求） |
| 5 | **不诱导** | 无默认勾选、无营销推送、不自动追加任何商品 |
| 6 | **说得清** | 不用专业词与网络新词：不说「随心配 / 核销 / 券包」，说「套餐 / 用了 / 优惠券」 |

### 5.2 四种取餐方式（P0 必须全部支持路由）

到店自取 / 得来速 / 麦乐送 / 企业团餐 —— 参数矩阵见 `references/be_type_matrix.md`。

### 5.3 两条正交维度

- **即时 vs 预约**：预约需传 `reservationDate`，格式 `yyyy-MM-dd HH:mm`
- **单点 vs 套餐改配**：改配依赖 `query-meal-detail` 的 `rounds`

## 六、非目标（明确不做什么）

写清楚"不做什么"和"做什么"同样重要：

| 不做 | 原因 |
|---|---|
| 库存 / 排班 / 销量报表 / 供应链 | **MCP 没有这些数据**，硬做就是编造 |
| 与肯德基、星巴克等其他品牌对比 | **官方规则明文禁止** |
| 大胃王 / 疯狂囤券 / 奢靡浪费类玩法 | 官方规则禁止「宣扬不健康饮食方式、奢靡浪费」 |
| 「帮老人占座 / 找地方聚会」类场景 | 涉及门店利益与舆论争议，品牌方可能不愿被关联 |
| 排队时长预测 | MCP 无排队数据，只能做预约 |
| 自动下单 / 免确认下单 | 违反设计标准（写操作必须可逆、需确认） |
| 默认勾选任何附加项 | 违反工信部规范（禁止诱导付款） |

## 七、成功标准（怎么算做到了）

| 维度 | 可验证标准 |
|---|---|
| 流程完整性 | 4 种取餐方式各有 1 条端到端真实跑通记录 |
| 决策质量 | 同一预算下产出 ≥3 个方案，**所有价格均来自 `calculate-price` 真实返回，零估算** |
| 失败显性化 | 业务失败（`success=false`）时**必须**抛出并展示原始 message，禁止伪造成功 |
| 安全闸门 | 未确认时写操作**必须被拦截**（需有反向测试证明） |
| 适老合规 | `references/design-standards.md` 中 P0 项全部通过 |
| 可理解性 | 一个陌生人在 30 秒内能说出「它和官方 App 有什么不一样」 |
