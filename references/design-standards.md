# 设计标准（对齐工信部适老化规范）

> 依据：《移动互联网应用（APP）适老化通用设计规范》《互联网网站适老化通用设计规范》（工信部，2021）
> 用法：本文件是**可验收清单**。P0 项未通过则不允许发布版本。

---

## 一、为什么一个对话式 Skill 也要遵守 APP/网页规范

因为本 Skill 的输出会以文本、卡片、表格形式呈现给用户，且涉及**财务交易**。规范中与交互形态无关的条目（用词、诱导、可撤销、隐私）对本项目**完全适用**，与前端形态无关的条目（点击区尺寸、手势）不适用。

**适用性判断（诚实标注）**：

| 规范类别 | 是否适用 | 说明 |
|---|---|---|
| 用词与可理解性 | ✅ 完全适用 | 输出语言直接相关 |
| 禁止诱导付款 | ✅ 完全适用 | 下单流程直接相关 |
| 财务交易可撤销 | ✅ 完全适用 | 下单流程直接相关 |
| 隐私最小必要 | ✅ 完全适用 | 涉及会员数据 |
| 字号 / 行距 / 对比度 | ⚠️ 部分适用 | 输出文本可控制；终端渲染不由本项目决定 |
| 点击区尺寸 / 手势 | ❌ 不适用 | 无自绘界面控件 |
| 验证码 | ❌ 不适用 | 不走自有验证码 |

## 二、P0 验收清单（必须全部通过）

### 2.1 语言与可理解性

- [ ] **不使用专业词与网络新词**：禁止出现「随心配」「核销」「券包」「私域」「LTO」「SKU」「SLOT」等
  - 替代对照：随心配 → 优惠套餐；核销 → 用了/使用；券包 → 优惠券；实付 → 实际付款
- [ ] **不使用编号或代号让用户猜**：不得要求用户说「3 号餐」，必须回显完整餐品名
- [ ] 每个状态变化都有**文字说明**，不依赖颜色/符号单独传达（例如不能只用 ⚠️ 表示失败，必须写清原因）
- [ ] 提供**撤销上一步**的路径（「算了」「重新选」）

### 2.2 反诱导（硬性）

- [ ] **无默认勾选**：任何附加商品、餐具、备注一律默认关闭
- [ ] **无营销推送**：不在点餐流程中插入无关活动推荐
- [ ] **无诱导付款**：不出现「限时」「仅剩」「马上就没了」等催促表达
- [ ] 不自动追加「加购」「凑单」——**凑单建议必须由用户主动询问**
- [ ] 金额三行分列：原价 / 优惠 / **实付**，不得只给总数

### 2.3 财务交易可撤销（规范核心条目）

- [ ] 下单前必须展示完整明细并获得**明确的、非默认的**确认
- [ ] 下单后**必须**输出撤销路径与时限：「订单可在 10 分钟内取消」，并给出取消方式
- [ ] 取消操作可执行（`cancel-order`，含取消原因码）
- [ ] 预约类订单同样提示可撤销

### 2.4 反馈与等待

- [ ] 每个耗时操作（多方案计价等）前给出说明，不让用户干等
- [ ] 不做超时自动推进；用户未回复时保持当前状态
- [ ] 失败必须给**下一步可做什么**，而不是只报错

### 2.5 隐私最小必要

- [ ] 不索取与点餐无关的个人信息
- [ ] 地址仅在使用时读取，不落盘到仓库
- [ ] **Token 只从环境变量读取**，任何文件中不得出现真实 Token
- [ ] 输出他人相关信息（如替家人点餐）时做脱敏，且不默认选中任何地址

## 三、P1 验收清单（尽量通过）

- [ ] 输出提供**大字版**：正文关键信息（餐品名、金额、取餐方式）单行独立展示，避免密集长句
- [ ] 输出段落之间留空行（对应规范中"段落间距 ≥ 行距 × 1.3"的可读性意图）
- [ ] 关键数字（金额、时间）不与修饰语混排
- [ ] 支持**语音优先**的表达路径：用户可用自然语言一句话完成，无需逐项回答
- [ ] 缩短流程步骤：默认值尽量前置，减少必答问题数

### 明确不适用于本项目的条目（记录以免误判合规）

| 规范条目 | 不适用原因 |
|---|---|
| 字号 ≥30dp、对比度 ≥4.5:1、点击区 ≥60×60dp | 无自绘 UI，终端渲染由客户端决定；本项目只保证文本层面的可读性 |
| 手势 ≤2 指、充足操作时间 | 无手势交互 |
| 验证码放大/替代 | 无验证码流程 |

> ⚠️ 诚实声明：本项目**不声称**「通过工信部适老化评测」。规范在此被用作**设计参照标准**，而非认证声明。对外表述应为「对齐/参照工信部适老化规范」，不得表述为「已通过适老化认证」。

## 四、检查方式

本文件 的 P0 项应逐条可验证：

| 检查项 | 验证方式 |
|---|---|
| 用词合规 | 对所有输出模板做词表扫描（禁用词清单写进 `scripts/render.py` 的常量） |
| 无默认勾选 | 代码审查 + 单测：`guard` 默认参数必须为关闭态 |
| 可撤销提示 | 下单回执模板必须包含撤销话术（单测断言字符串存在） |
| 金额三行 | 渲染函数输出结构断言 |
| Token 不入库 | 提交前扫描（已配置 `.gitignore`，仍需人工确认一次） |
