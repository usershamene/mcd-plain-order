# 错误码与处置手册

> 全部来自实测（真实 Token，2026-10-11），非文档推测。
> ⚠️ 核心前提：**业务失败不走 MCP 的 isError**，返回的仍是"正常结果"，只有 `success=false`。

---

## 一、统一响应信封

```json
{ "success": true, "code": 200, "message": "请求成功",
  "datetime": "2026-10-11 09:07:38", "traceId": "...", "data": { ... } }
```

判断规则（**确定性逻辑，写在代码里**）：

```
success == true 且 code == 200  →  业务成功
success == false               →  业务失败，必须原文展示 message，禁止伪造成功
HTTP 401 / 429                 →  鉴权失败 / 限流（协议层，非业务层）
```

`traceId` 应保留，便于排查。

---

## 二、协议层错误

| 码 | 现象 | 原因 | 处置 |
|---|---|---|---|
| HTTP 401 | MCP 层报错 | Token 无效 / 过期 / 未提供 | 提示重新申请；检查 `Authorization` 是否为 `Bearer <Token>` |
| HTTP 429 | 限流 | 超过 **600 次/分钟** | 串行化 + 指数退避；不要静默重试丢弃 |
| HTTP 403 + code 400003 | 「校验鉴权authToken必填」 | **`Bearer ` 前缀丢失**（实测踩过） | 补回 `Bearer ` 前缀 |

## 三、业务层错误（`success=false`）

| code | message | 触发场景 | 处置 |
|---|---|---|---|
| **60002** | 未查询到门店信息, 检查storeCode和beCode是否配对 | 门店编码错 / beCode 与 beType 不配 | 按 `references/be_type_matrix.md` 重查参数；**不要猜** |
| **600050** | 收藏餐厅列表为空，请您提供城市+关键词进行搜索 | `searchType=1` 但用户无收藏门店 | 回退到 `searchType=2`，向用户索要城市 + 地点关键词 |
| **600057** | 门店可能已关闭或不在营业时间 | 非营业时段查菜单（实测 23:50 失败） | 提示营业时间，建议换门店或改用预约 |

## 四、易被误判为成功的场景（必须拦截）

| 场景 | 危险 | 正确做法 |
|---|---|---|
| 下单失败但返回正常结构 | 用户以为下单成功 | 必须检查 `success`，失败时明确告知 |
| 门店可用券返回空数组 `[]` | 被当成"查询失败" | **空数组是正常结果**（表示该店无可用券），不是错误 |
| 券的 `reducePrice` 为空字符串 | 被当成 ¥0 优惠 | 优惠金额**不可从券接口取得**；以 `calculate-price` 为准 |
| `campaign-calendar` 顶层字段为空 | 被当成"没有活动" | 真内容在 `articleDto.title/content`；顶层字段（activityTitle/price）实测大量为空 |
| `list-nutrition-foods` 返回字符串 | 被当成 JSON 解析失败 | 它是**压缩表格字符串**，格式 `「160」{字段名}: 行数据`，需自写解析 |

## 五、参数格式速查

| 字段 | 格式 | 备注 |
|---|---|---|
| `reservationDate` | `yyyy-MM-dd HH:mm` | 仅预约场景传，非预约不要传 |
| `storeCode` | 纯数字字符串 | 实测如 `3330492` |
| `beCode` | 数字字符串 | 实测如 `333054841`；**到店自取不传** |
| `cancelReasonCode` | 1 / 2 / 3 / 4 / 5 / -1 | 1改主意 2重复下单 3点错 4地址电话错 5时间错 -1其它 |
| `remark` | ≤50 字 | 仅外送场景 |
| `weekdays`（券） | 1=周日 2=周一 … 7=周六 | **实测反推**（12 个数据点验证），非官方文档 |
| `tradeTimePeriods` | `[{"startTime":"05:00:00","endTime":"10:29:59"}]` | 日内可用窗口 |
| `catRuleIds` | 逗号分隔，如 `1>4,2` | 商品券 `1>4`、实物 `2`、周边 `2>8`、派对 `1>6>20` 等 |
